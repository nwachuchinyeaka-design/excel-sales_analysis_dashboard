# Excel Sales Analysis Dashboard

## 1. Project Overview

This project involves analyzing sales data using Microsoft Excel
to explore revenue performance, identify trends, and generate
insights that can support business decision-making.

The project demonstrates the use of Excel for data preparation,
analysis, and visualization through an interactive dashboard.

## 2. Project Objectives

- Analyze revenue across different countries and regions.
- Compare sales performance across product categories.
- Examine revenue by order priority.
- Present key findings through charts and an interactive dashboard.

## 3. Tools and Skills

- Microsoft Excel
- Power Query
- Data Cleaning and Preparation
- PivotTables and PivotCharts
- Excel Slicers
- Data Visualization
- Business Data Analysis
