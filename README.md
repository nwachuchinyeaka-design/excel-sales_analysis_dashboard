# Excel Sales Analysis Dashboard

## 1. Project Overview

This project involves analyzing sales data using Microsoft Excel
to explore revenue performance, identify trends, and generate
insights that can support business decision-making.

The project demonstrates the use of Excel for data preparation,
analysis, and visualization through an interactive dashboard.

## 2. Project Objectives

- Analyze revenue across different countries and regions.
- Compare sales performance across product categories.
- Examine revenue by order priority.
- Present key findings through charts and an interactive dashboard.

## 3. Tools and Skills

- Microsoft Excel
- Power Query
- Data Cleaning and Preparation
- PivotTables and PivotCharts
- Excel Slicers
- Data Visualization
- Business Data Analysis

## 4. Project Process

### Data Preparation
Reviewed the dataset, checked data types, and addressed
inconsistencies where necessary.

### Data Analysis
Used Excel analysis tools to summarize sales data and
investigate revenue performance across relevant categories.

### Data Visualization
Created charts and an interactive dashboard to present
the analysis in a clear and accessible format.

## 5. Key Findings

The analysis explored sales revenue across countries,
regions, product categories, and order priorities.

**###1. Regional Sales Volume**
- North America recorded the highest sales volume, with 87,441 units sold.
- Asia recorded the lowest sales volume, with 71,853 units sold.

### 2. Revenue by Order Priority
- High-priority orders generated the highest revenue, totaling 643,239,850.00.
- Critical-priority orders generated the lowest revenue, totaling 579,660,131.20.
- The revenue difference between High and Critical priority orders was 63,579,718.80.

### 3. Unit Cost by Country
- Australia recorded the highest total unit cost, with a Sum of Unit Cost of 300,246.07.
