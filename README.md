# Excel Sales Analysis Dashboard

## Project Overview

This project uses Microsoft Excel to analyze sales data,
explore revenue performance, and present insights through
an interactive dashboard.

## Objectives

- Analyze revenue across different countries and regions.
- Compare sales performance across product categories.
- Explore revenue by order priority.
- Present findings using charts and an interactive dashboard.

## Tools and Skills

- Microsoft Excel
- Power Query
- Data Cleaning
- PivotTables and PivotCharts
- Slicers
- Data Visualization

## Project Process

1. Examined and prepared the dataset.
2. Cleaned inconsistent data where necessary.
3. Performed analysis using PivotTables and calculations.
4. Created charts to explore sales performance.
5. Built an interactive dashboard.
